# 개인정보 / 회사 데이터 규칙

## 회사 데이터 — 3층 분류

| 층 | 내용 | 처리 |
|---|---|---|
| 금지 | 소스코드, 장비 스펙, 고객사명, 도면, 내부 문서 | 수집기에서 차단. 저장 자체를 하지 않음 |
| 추상화 후 허용 | 기술적 판단·교훈 ("E84 타임아웃은 이렇게 잡는 게 맞다") | 고유명사 제거 후 저장 |
| 허용 | 생각·고민·방향 ("외주 통합 방식 고민 중") | 그대로 저장 |

## 수집기 단계 필터 (`collectors/filters.py`)

- 금지어 사전: 고객사명, 프로젝트 코드명, 내부 호스트명 → 매칭 시 해당 item 폐기 + 로그
- 코드 블록(``` 또는 들여쓰기 4칸 이상 연속 3줄) 포함 item → 폐기
- 파일 경로 패턴(`C:\`, `\\server\`) → 마스킹

## 외부 LLM 전송

- `process/llm.py`만 외부 호출 가능
- 전송 전 텍스트를 `data/llm_outbox.log`에 기록 (무엇이 나갔는지 추적)
- 메모리 `fact` 타입 중 민감 표시된 것은 프롬프트에 포함하지 않음

## 저장 위치

- 원본·DB는 NAS 로컬. 외부 포트 노출 없음
- vault는 Obsidian Sync 또는 개인 Gitea. 공개 repo 금지
- `.env`, `data/`는 `.gitignore`

## 자기 감시 방지

브리핑·리포트는 다음을 출력하지 않는다:
- 시간 합계 ("유튜브 3시간")
- 비교·평가 ("지난주보다 집중력 저하")
- 권고 ("~해야 합니다")

기록과 연결만 한다.
