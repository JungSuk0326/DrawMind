# 일일 브리핑 형식

`vault/daily/YYYY-MM-DD.md` — 야간 배치가 생성. 아침에 읽는 데 2분 이내.

```markdown
---
date: 2026-11-10
sources: [voice, claude]
items: 14
---

# 2026-11-10

## 어제의 흐름
한 문단. 시간 순서로 "무엇을 생각했나". 평가 없음.

## 이어지는 고민 (threads)
- [[PMAC 외주 통합]] — 어제 음성메모 2건. 상태: 미결
- [[생각 수집 시스템]] — Claude 대화 1건. 1단계 설계 확정

## 새로 등장한 것
- 처음 나온 주제·키워드. 없으면 섹션 생략

## 미해결 질문
- 회사 PC 외부 접근 허용 범위?

## 원본
- 09:12 voice — "..." (처음 40자) → [[raw/voice/2026-11-10#1]]
- 14:30 claude — "생각 시각화 파이프라인 질문" → [[raw/claude/...]]
```

## 규칙

- 모든 요약 문장은 원본 링크로 내려갈 수 있어야 한다
- "어제의 흐름"은 5문장 이내
- 데이터가 없는 날은 파일을 만들지 않는다 (빈 브리핑 금지)
- threads 섹션의 [[링크]]는 `vault/threads/` 노트와 연결 — Obsidian graph의 뼈대
